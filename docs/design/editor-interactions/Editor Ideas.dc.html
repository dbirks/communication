Editor ideas

From the review of Prototype v2 against main. Each idea stands on its own and builds on the section 8 visual language. 1c and 1d draw the loop with the 1g ink-tab frame.

1aOne card beside the selection

Whatever you select gets the same card in the same place: 18px to the right, caret on the selection's middle, 340 wide, the 3px floating shadow. One step opens the step card (main's AgentStepCard), several open the wrap panel, a note opens the note editor. Only one is open at a time.
