# Add a project

A project is the team's container: it holds the repositories, the workflow
assignments, the members and the secret references.

1. Open **Projects** in the sidebar (the `/projects` page).
2. Choose **New project**.
3. Type a name — the slug and the colour follow from it. A description is
   optional.
4. Choose **Create project**. The new project appears in the sidebar.

The assistant can do the same thing as you: `project.create` is a change tool,
so it asks on a card before anything is created, and it can add the first
repository in the same confirmation.

Who can do it: any signed-in member can create a project and is its
maintainer. Editing an existing project needs the maintainer role on that
project.
