 11 The run header packs everything into one line
 RUN WORKBENCH MEDIUM 
 ✓ DECIDED A labeled facts row and one primary action chosen by run state. The other actions go in a ⋯ menu. 
 RunHeader puts the workflow slug, repository, revision number, a 12-character digest, "(pinned)", start age and actor into one 11px mono sentence. The stream status ("live") sits next to the state chip in the same weight as the title row. Up to five buttons share the right side: Open pinned workflow, Fix the workflow…, and RunActions' Pause, Cancel and Retry. Nothing in that layout says which button matters for this run's state.
